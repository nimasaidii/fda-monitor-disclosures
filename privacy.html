FDA Food Inspection Monitor

Privacy policy

Effective October 30, 2026

This utility is operated for its owner's personal FDA monitoring. It is not a public email, marketing, or customer-management service.

Google account access

The utility requests only the Gmail permission gmail.send. With the owner's consent, it sends grouped FDA-record notifications to the owner's own email address. It does not request access to read, search, delete, or modify inbox messages, contacts, calendars, or Drive files.

Information used and stored

The utility uses public FDA company, facility, inspection, citation, recall, warning-letter, and compliance records. It also uses the configured sender and recipient address, OAuth credentials, and Gmail's delivery message identifiers. It stores FDA record history and delivery receipts to identify changes and prevent repeated notifications.

Storage and service providers

The monitor runs in a private GitHub repository using GitHub Actions. OAuth refresh credentials and FDA API credentials are stored in encrypted GitHub Actions secrets and provided to authorized runs. Public FDA-record history and delivery receipts are stored as checkpoints accessible through the private repository. Google processes notification messages through the Gmail API. During setup, temporary local credential files may be used only to complete authorization and transfer credentials to private secrets storage, then removed.

Use and sharing

Google account information and credentials are used only to provide the owner's requested notifications. They are not sold, used for advertising, shared for marketing, or used to train artificial intelligence models. Access by Google and GitHub is limited to operating the described authorization, mail delivery, and hosting services.

Retention, control, and deletion

The owner can revoke the utility's access through Google Account security settings and disable the GitHub Actions workflow. The owner can remove stored credentials, private checkpoints, and reports. Checkpoints retain recent generations for recovery; FDA history and delivery receipts remain until removed by the owner. Copies of delivered email remain subject to the owner's Gmail settings and deletion choices.

Questions

The owner controls the utility and its settings. Contact details for the app owner are available through the user-support address displayed on Google's consent screen.

Google API data policy

The utility's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This disclosure page has no analytics, advertising, tracking scripts, or embedded third-party media. Its hosting provider may process ordinary web-server request information.
